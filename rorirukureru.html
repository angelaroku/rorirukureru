"RORIRU KURERU" - ¿Qué es?

El nombre de "roriru kureru", nace de una degradación de palabras y sonidos sin sentido, los cuáles con el tiempo fueron tomando forma y se convirtieron en el nombre de un proyecto sonoro.
Hablando con sinceridad, "roriru kureru", no es un nombre intuitivo, ni simple de recordar por eso para simplificarlo, se acorta de esta manera: "RO" + "KU" = roku

La base de este proyecto sonoro, es la precariedad de recursos, de esta manera, con poco y sin mucho sentido, de forma orgánica se fué generando una esencia particular y la propia vibra del proyecto cobró vida por inercia. La plataforma inicial para compartir siempre fue SoundCloud, pero poco a poco se amplió a otras plataforma como Instagram o Youtube.
